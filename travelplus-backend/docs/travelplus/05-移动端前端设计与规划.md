## 1. 目标与范围

### 1.1 目标

为 TravelPlus 提供一个简洁干净的移动端 H5 前端，无构建、无依赖，浏览器直接打开即可使用，覆盖平台核心链路：**登录 → 景点浏览/搜索 → 景点详情与门票秒杀 → 游记热门/详情/点赞/发布 → 关注 Feed → 个人中心与签到**。

### 1.2 功能范围

| 功能域 | 覆盖内容 | 对应后端接口 |
|---|---|---|
| 登录 | 手机号 + 验证码登录，token 本地缓存 | `/user/code`、`/user/login` |
| 景点浏览/搜索 | 类型 tab 切换、按类型分页、按名称搜索 | `/attraction-type/list`、`/attraction/of/type`、`/attraction/of/name` |
| 景点详情与门票秒杀 | 景点信息、门票列表、秒杀下单 | `/attraction/{id}`、`/ticket/list/{attractionId}`、`/ticket-order/seckill/{ticketId}` |
| 游记热门/详情/点赞/发布 | 热门列表、详情、点赞切换、发布、图片上传 | `/note/hot`、`/note/{id}`、`/note/like/{id}`、`/note`、`/upload/note` |
| 关注 Feed | 关注人游记流（滚动分页）、关注/取关 | `/note/of/follow`、`/follow/**` |
| 个人中心与签到 | 用户信息、签到、签到统计、我的游记 | `/user/me`、`/user/sign`、`/user/sign/count`、`/note/of/me` |

## 2. 技术选型与理由

| 项 | 选型 | 理由 |
|---|---|---|
| 技术栈 | 纯静态原生 HTML/CSS/JS | 零构建、零依赖、浏览器直接运行；教学演示项目无前端工程化诉求 |
| 模块化 | ES Modules（`<script type="module">`） | 原生模块化能力，无需打包器；按页面拆文件，职责清晰 |
| 路由 | hash 路由（`#/xxx`） | 纯静态文件无法配置服务器路由，hash 刷新不 404 |
| 服务端口 | 前端独立静态服务 19608 | 与后端 8081 完全分离；`python -m http.server 19608` 即可运行 |
| 跨域 | 后端 MvcConfig CORS 放行 | 前端 19608 → 后端 8081 属跨域，浏览器默认拦截，由后端统一放行（见第 4 节） |

## 3. 前后端对接契约

### 3.1 通用约定

- 后端端口 **8081**；前端统一从 `API_BASE = http://localhost:8081` 发起请求
- 鉴权头 **`authorization`**（小写）= 登录接口返回的 token
- 统一返回结构 `Result: {success, errorMsg, data, total}`；`success=false` 时取 `errorMsg` 提示用户；jackson 配置 `non_null`，null 字段不输出
- 未登录访问需登录接口 → HTTP **401**

### 3.2 放行 / 鉴权分类

放行路径（无需 token，来自 `MvcConfig.addInterceptors` 的 `excludePathPatterns`，与 notepad 放行清单一致）：

```
/attraction/**   /ticket/**   /attraction-type/**   /upload/**   /imgs/**   /error   /note/hot   /user/code   /user/login
```

（实现时在 `excludePathPatterns` 追加了 `/imgs/**` 与 `/error`：图片匿名访问；缺失资源 404 不再被吞成 401。另见第 4 节的 OPTIONS 预检放行。）

**其余所有路径均需登录**（未登录返回 401），包括 `/user/me`、`/user/sign`、`/note`（POST）、`/note/like/**`、`/note/{id}`、`/note/likes/{id}`、`/note/of/me`、`/note/of/user`、`/note/of/follow`、`/follow/**`、`/ticket-order/**`、`/user/logout` 等。

### 3.5 限流与未实现标注

- **限流**：`GET /attraction/of/type` 标注 `@RateLimiter`（`window=5` 秒，`limit=5` 次，METHOD 维度），超限返回 fail，完整文案"查询次数过多，请稍后再试"。前端需对类型切换做节流/防抖，避免高频请求触发限流。
- **未实现（2026-08-06 已补全）**：`/note-comments` 评论接口与 `/user/logout` 服务端登出均已实现（见第 9 节）。前端已启用真实评论区、密码/验证码切换登录与注册页。

## 4. 后端最小改动说明（MvcConfig）

改动落在 `src/main/java/com/travelplus/config/MvcConfig.java` 与 `src/main/java/com/travelplus/utils/LoginInterceptor.java`，共四处：

| 改动 | 实现 | 原因 |
|---|---|---|
| CORS 放行 | `addCorsMappings`：`/**`，`allowedOriginPatterns("*")`，方法 GET/POST/PUT/DELETE/OPTIONS，`allowedHeaders("*")`（含 `authorization`），`maxAge=3600` | 前端运行在独立端口 19608，跨域请求会被浏览器拦截；必须放行 `authorization` 头，否则登录 token 无法随请求携带 |
| `/imgs/**` 静态映射 | `addResourceHandlers`：`/imgs/**` → `file:` + `SystemConstants.IMAGE_UPLOAD_DIR`（随项目位置自动解析，当前为 `E:\AAAproject\travelplus\uploads\imgs\`），并自动 `mkdirs()` 确保目录存在 | 无 nginx 直出场景下图片需由后端直接提供；映射后 `IMG_BASE` 直接使用 `http://localhost:8081` 即可访问种子图片与上传图片 |
| 拦截器放行补充 | `excludePathPatterns` 在放行清单基础上追加 `/imgs/**` 与 `/error` | 图片匿名访问；缺失资源 404 不再被登录拦截器吞成 401 |
| CORS 预检放行 | `LoginInterceptor.preHandle` 对 OPTIONS 请求直接 `return true` | 浏览器 CORS 预检（OPTIONS）无 `authorization` 头，会被登录拦截器 401 拦截导致跨域失败 |

实施记录见 03-过程记录.md「移动端前端实现记录」。

## 7. 鉴权与图片 URL 规则

### 7.1 鉴权规则

1. 登录成功，`data=token` 存入 localStorage（key `travelplus_token`），用户信息存 `travelplus_user`。
2. 每次请求携带请求头 `authorization: <token>`（小写，与后端 `RefreshTokenInterceptor` 读取的头部一致）。
3. 收到 **HTTP 401**（登录过期/未登录）：清除 token 与用户缓存，跳转 `#/login?redirect=<当前路由>`，登录成功后回跳。
4. 由于除白名单外的接口全部需登录（见 3.2），页面路由在加载时先校验登录态，未登录跳转登录页。

### 7.2 图片 URL 规则

| 数据来源 | 拼接规则 | 示例 |
|---|---|---|
| DB 景点/游记图片（`images` 字段） | 路径已带 `/imgs/` 前缀 → `IMG_BASE + 路径` | `IMG_BASE + /imgs/blogs/blog1.jpg` |
| 上传接口返回相对名 | 不带 `/imgs/` 前缀 → `IMG_BASE + '/imgs/' + 相对名` | `IMG_BASE + /imgs/blogs/d1/d2/uuid.jpg` |

`IMG_BASE = API_BASE = http://localhost:8081`（依赖后端 `/imgs/**` 静态映射）。

### 7.3 单位换算规则

| 字段 | 存储单位 | 展示 |
|---|---|---|
| `Ticket.payValue` / `actualValue` | 分 | ÷100（元） |
| `Attraction.score` | ×10 | ÷10 |
| `Attraction.avgPrice`、`sold`、`comments`、`TravelNote.liked/comments` | 原值 | 直接展示 |

## 8. 运行与验证步骤

### 8.1 启动后端

```powershell
mvn spring-boot:run
```

依赖容器需全部 Up：`travelplus-mysql`（3307）、`company-agent-redis`（6379）、`travelplus-kafka`（9092）。日志出现 `Started TravelPlusApplication` 即启动成功（后端端口 8081）。

### 8.2 启动前端

在 `travelplus-frontend/` 目录下启动静态服务：

```powershell
python -m http.server 19608
```

浏览器访问 `http://localhost:19608`。

### 8.3 登录验证码获取途径

验证码不真实发送短信，仅存两处：

1. **后端日志**：`/user/code` 打印验证码。
2. **Redis**（无密码）：`docker exec company-agent-redis redis-cli GET login:code:13686869696`

种子用户：`13686869696`（小鱼同学 id=1）、`13838411438`（id=2）。
