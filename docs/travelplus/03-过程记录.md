- **SQL 导入**：`docker cp src\main\resources\db\hmdp.sql travelplus-mysql:/tmp/hmdp.sql` 后执行 `mysql hmdp < /tmp/hmdp.sql`
  - ⚠️ 经验教训：原始 hmdp.sql 含 MySQL 5.7 风格 `DEFAULT '0000-00-00 00:00:00'`，MySQL 8.0 默认 `sql_mode` 下报 `ERROR 1067 Invalid default value for 'begin_time'`。解决：导入前执行 `SET SESSION sql_mode='ONLY_FULL_GROUP_BY,STRICT_TRANS_TABLES,ERROR_FOR_DIVISION_BY_ZERO,NO_ENGINE_SUBSTITUTION'`（去掉 NO_ZERO_DATE / NO_ZERO_IN_DATE）。SQL 文件未做任何修改。**B3 导入 travelplus.sql 时必须使用同样的 sql_mode 处理。**
- **导入验证**：SHOW TABLES 得 10 张表；`SELECT COUNT(*) FROM tb_shop` = 14
- **容器 travelplus-kafka**：镜像 `apache/kafka:3.7.0`（KRaft 单节点），端口 `9092->9092`；`Test-NetConnection 127.0.0.1 9092` → True
