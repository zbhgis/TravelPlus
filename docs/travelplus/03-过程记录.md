## A2 记录（2026-08-04）

- **容器 travelplus-mysql**：镜像 `mysql:8.0`，端口 `3307->3306`（3306 被 company-agent-mysql 占用，改用 3307），root 密码 `123456`，初始库 `hmdp`
- **SQL 导入**：`docker cp src\main\resources\db\hmdp.sql travelplus-mysql:/tmp/hmdp.sql` 后执行 `mysql hmdp < /tmp/hmdp.sql`
  - ⚠️ 经验教训：原始 hmdp.sql 含 MySQL 5.7 风格 `DEFAULT '0000-00-00 00:00:00'`，MySQL 8.0 默认 `sql_mode` 下报 `ERROR 1067 Invalid default value for 'begin_time'`。解决：导入前执行 `SET SESSION sql_mode='ONLY_FULL_GROUP_BY,STRICT_TRANS_TABLES,ERROR_FOR_DIVISION_BY_ZERO,NO_ENGINE_SUBSTITUTION'`（去掉 NO_ZERO_DATE / NO_ZERO_IN_DATE）。SQL 文件未做任何修改。**B3 导入 travelplus.sql 时必须使用同样的 sql_mode 处理。**
- **导入验证**：SHOW TABLES 得 10 张表（tb_blog、tb_blog_comments、tb_follow、tb_seckill_voucher、tb_shop、tb_shop_type、tb_user、tb_user_info、tb_voucher、tb_voucher_order）；`SELECT COUNT(*) FROM tb_shop` = 14
- **容器 travelplus-kafka**：镜像 `apache/kafka:3.7.0`（KRaft 单节点），端口 `9092->9092`
- **连通验证**：`Test-NetConnection -ComputerName 127.0.0.1 -Port 9092 -InformationLevel Quiet` → `True`
- **结果**：成功。两个容器运行中。
