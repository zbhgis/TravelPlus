## A2 记录（2026-08-04）

- **任务**：A2 Docker 基础设施（MySQL 3307 + Kafka 9092）+ 初始数据导入
- **容器 travelplus-mysql**：镜像 `mysql:8.0`，端口 `3307->3306`（3306 被 company-agent-mysql 占用故用 3307），root 密码 `123456`，初始库 `hmdp`
- **SQL 导入**：`docker cp src\main\resources\db\hmdp.sql travelplus-mysql:/tmp/hmdp.sql` 后执行 `mysql hmdp < /tmp/hmdp.sql`
  - 注意：原始 hmdp.sql 含 MySQL 5.7 风格的 `DEFAULT '0000-00-00 00:00:00'`，MySQL 8.0 默认 `sql_mode` 下报 `ERROR 1067 Invalid default value for 'begin_time'`，故导入前以 `SET SESSION sql_mode='ONLY_FULL_GROUP_BY,STRICT_TRANS_TABLES,ERROR_FOR_DIVISION_BY_ZERO,NO_ENGINE_SUBSTITUTION'`（去掉 NO_ZERO_DATE / NO_ZERO_IN_DATE）规避；SQL 文件未做任何修改
- **导入验证输出（SHOW TABLES）**：tb_blog、tb_blog_comments、tb_follow、tb_seckill_voucher、tb_shop、tb_shop_type、tb_user、tb_user_info、tb_voucher、tb_voucher_order（共 10 张表）
- **导入验证输出（SELECT）**：`SELECT COUNT(*) FROM tb_shop` = 14
- **容器 travelplus-kafka**：镜像 `apache/kafka:3.7.0`（KRaft 单节点），端口 `9092->9092`
- **连通验证**：`Test-NetConnection -ComputerName 127.0.0.1 -Port 9092 -InformationLevel Quiet` 首次重试即返回 `True`
- **结果**：成功。两个容器均运行中。
