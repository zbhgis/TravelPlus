> 分支：`travelplus-migration` ｜ 报告日期：2026-08-05 ｜ 门禁：B6 完成门禁

## 一、改造概述

将原 hm-dianping（Spring Boot 2.3.12 / Java 8 黑马点评）迁移并改造为旅游服务平台 TravelPlus，全程遵循两条铁律：

1. **零逻辑改动**：所有方法体、控制流、事务、异常处理保持原样，仅做命名/环境迁移；
2. **半成品保留**：`KafkaConfig` 注释 Bean、`SeckillTicketConsumer` 注释的 `@KafkaListener`、`seckill.lua` 注释的 xadd 行保持注释状态；图片路径 `/imgs/blogs/`、`/blogs/{}/{}` 存储格式串永不替换（白名单）。

改造分两阶段：

- **阶段 A**（Java 24 环境迁移）：Docker 基础设施 + 依赖栈升级（Boot 3.5.9 / MyBatis-Plus 3.5.17 / Lombok 1.18.38）+ javax→jakarta 机械迁移 + 编译/启动冒烟门禁；
- **阶段 B**（全链路场景替换）：包名 `com.hmdp`→`com.travelplus`、类名/标识符长词优先替换（Shop→Attraction、Voucher→Ticket、Blog→TravelNote）、数据库脚本 travelplus.sql、配置/Lua/pom 身份、文档同步。
