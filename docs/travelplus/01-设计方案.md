# TravelPlus 改造设计方案

- 日期：2026-08-04
- 状态：已确认（用户授权"按最佳想法执行"）
- 范围：hm-dianping → TravelPlus，分两个阶段：**A. Java 24 环境迁移（先行）** → **B. 旅游域全链路场景替换**

---

## 1. 背景与目标

本项目为"黑马点评"教学项目（Spring Boot 2.3.12 / Java 8 时代技术栈），用户目标：

1. **环境先行**：用户本机只有 JDK 24 可用（`JAVA_HOME=D:\Program Files\Java\jdk-24`），项目必须能在 Java 24 下编译、运行。
2. **场景改造**：全链路语义改造为旅游平台 **TravelPlus**——Java 类名/变量名、包名、URL、Redis key、Kafka topic、数据库表名/SQL、注释文案全部换成旅游域语义，改完看不出点评痕迹。
3. **记录要求**：方案与过程用若干 MD 文件记录于项目内（见第 6 节）。

## 2. 铁律（约束）

1. **零逻辑改动**：所有方法体、控制流、事务、异常处理保持原样。
2. **半成品保留**：注释掉的代码块（`KafkaConfig` 的 Bean、`SeckillVoucherConsumer` 的 `@KafkaListener`、`seckill.lua` 的 xadd 行）保持注释状态；`logout()` 占位返回"功能未完成"保留；未使用变量（如 `int r = result.intValue();`）不清理；课程章节标记【秒杀链路消息队列使用】-1/-2/-3、【多级缓存改造】等编号注释保留。
3. **不修 bug、不做代码清理、不加新功能**。
4. **唯一例外**：阶段 A 中框架升级**强制要求**的 API/命名空间迁移（javax→jakarta、依赖版本、配置属性改名），行为必须等价。

## 3. 阶段 A：Java 24 环境迁移

### 3.1 为什么必须升级整个技术栈

Spring Boot 2.3.12（Spring Framework 5.2）官方不支持 Java 24：其内置 ASM 无法解析高版本 class 文件、托管的 Lombok 1.18.20 在 JDK 24 上直接崩溃（`ExceptionInInitializerError: com.sun.tools.javac.code.TypeTag`）。在旧栈上打补丁（add-opens、降字节码目标）脆弱且无官方支持。**结论：升级到官方支持 Java 24 的 Spring Boot 3.5.x。**

## 4. 阶段 B：TravelPlus 全链路场景替换

### 4.1 执行策略

**分阶段有序替换 + 每阶段编译门禁**（长词优先，避免子串撞车）：
`SeckillVoucher` 必须先于 `Voucher` 替换；`VoucherOrder` 先于 `Voucher`；`ShopType` 先于 `Shop`；`BlogComments` 先于 `Blog`。每个概念覆盖全部形态：PascalCase / camelCase / snake_case / kebab-case / 中文。

### 4.2 核心实体映射（用户已确认）

| 原类名 | 新类名 | 旅游语义 |
|---|---|---|
| Shop | **Attraction** | 景点 |
| ShopType | **AttractionType** | 景点类型 |
| Blog | **TravelNote** | 游记 |
| BlogComments | **TravelNoteComment** | 游记评论 |
| Voucher | **Ticket** | 门票 |
| SeckillVoucher | **SeckillTicket** | 秒杀特价票 |

### 4.4 种子数据替换（SQL 内容，非逻辑）

- **tb_attraction（原 tb_shop）14 行**：餐厅/KTV → 杭州景点（西湖、灵隐寺、宋城、西溪湿地、雷峰塔、六和塔、断桥、苏堤等），坐标换为对应景点真实经纬度（保持"附近景点"GEO 演示可用），地址同步改写
- **tb_attraction_type（原 tb_shop_type）10 行**：美食/KTV/丽人美发… → 自然风光/人文古迹/主题乐园/博物馆/寺庙/湖泊山水/公园/文化街区/亲子出游/演出展览；图标路径 `/types/*.png` 不变（前端资源归属）

- **tb_travel_note（原 tb_blog）**：标题/正文/图片全部保留原文（含两条探店风格文案，属演示数据，不做内容重写）
- **UploadController 存储路径**：`/blogs/{}/{}` 目录格式串与 `/imgs/blogs/` 数据路径**保留不变**（存储层布局，与种子图片路径及课程前端 nginx 布局保持一致）；仅 URL 层 `/upload/blog` → `/upload/note`。残留 grep 将这两类路径字符串列入白名单

## 6. 风险与回滚

| 风险 | 对策 |
|---|---|
| 子串撞车（Voucher 先于 SeckillVoucher 被替换） | 长词优先顺序 + 全形态覆盖 + 残留 grep 兜底 |
| Boot 3 行为差异 | 本项目无 trailing-slash 路由、无 actuator、无 validation，差异面极小；冒烟验证兜底 |
| 依赖版本解析失败 | 编译门禁当场发现，换用仓库内可用的相邻版本 |
| 任何阶段失败 | Git 分支 `travelplus-migration` 上操作，主干随时可回退 |
| Maven 下载失败 | 备选：Docker `maven:3.9-eclipse-temurin-24` 镜像内编译 |
