# 积分抵扣同步（points-1-deduct）

## 2026-08-12 · 前端 order-detail.js 积分抵扣逻辑同步

**背景**：后端已改为任意正整数积分均可抵扣（1 积分 = 0.01 元），不再要求 100 的整数倍。前端支付区原按"每 100 积分抵 1 元"实现，已同步。

**修改文件**：`travelplus-frontend/js/pages/order-detail.js`（仅此一个文件）

### 改动明细
1. **抵扣计算**：`usePoints / 100`（保留 2 位），不再 `Math.floor(pts/100)*100` 取整百；实时"应付 ¥xx.xx" = 原价 - 抵扣，最低 0.01。
2. **快捷按钮**：100/200/500 → **10 / 50 / 100 / 200**；输入框 `step=100` → `step="1"`，允许任意正整数。
3. **文案**：标签改"积分抵扣（1 积分抵 0.01 元，可任意数量抵扣）"；确认弹窗"使用 X 积分抵扣 ¥X，实付 ¥Y 吗？"沿用新算法（原逻辑已按 /100，无需改）。
4. **边界**：
   - `usePoints > 可用积分` → 前端 `toast('积分不足，最多可用 X 积分')` + 封顶为 walletPoints（后端 fail 兜底，api.js 已统一 toast）。
   - 输入非数字/空 → `parseInt || 0` → 0 不抵扣；负数归 0。
5. 同步更新了文件头部注释（快捷 10/50/100/200、1 积分抵 0.01 元）。
